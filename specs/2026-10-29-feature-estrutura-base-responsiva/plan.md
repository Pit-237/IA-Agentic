# Plano

## 1. Estrutura do projeto

1.1. Preparar a aplicação React com TypeScript e Vite.
1.2. Organizar páginas, componentes e estilos da base institucional.
1.3. Confirmar os comandos de desenvolvimento e build.

## 2. Base visual

2.1. Consultar o site antigo como referência de conteúdo e identidade.
2.2. Definir fundamentos visuais com direção técnica e editorial.
2.3. Criar a estrutura responsiva com cabeçalho, navegação e rodapé.
2.4. Preparar áreas provisórias para cursos e notícias na página inicial.

## 3. Verificação

3.1. Conferir navegação, legibilidade e adaptação a telas móveis.
3.2. Executar build e verificações disponíveis no projeto.
3.3. Registrar resultados e pendências em `validation.md`.
