# Requisitos

## Escopo

Entregar a estrutura inicial do site institucional e uma página inicial responsiva, com navegação e áreas provisórias para conteúdo futuro. Esta fase não implementa catálogo completo, notícias funcionais, login, API ou persistência.

## Decisões

- Usar React, TypeScript e Vite no frontend.
- Seguir uma direção visual técnica e editorial.
- Manter backend e acesso ao SQLite fora desta fase.
- Usar placeholders nas áreas de cursos e notícias até as fases correspondentes.

## Contexto

- A missão é informar e orientar estudantes e a comunidade sobre a escola, cursos e notícias.
- A experiência deve ser atraente, confiável e utilizável em navegadores modernos e dispositivos móveis.
- Consultar como referência o site antigo: https://etecsalesgomes.cps.sp.gov.br/ensino-tecnico/.
- A integração com SQLite deve ocorrer no servidor por uma API, conforme `specs/tech-stack.md`; o framework de backend ainda será definido.
